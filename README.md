# Sadhana Chaudhary - Portfolio

![Portfolio Preview](./frontend/public/profile.png)

A modern, responsive portfolio built with **React, Vite, and Tailwind CSS**, featuring a custom mobile app showcase and a fully functional contact form powered by a **Node.js/Express** backend and **Nodemailer**.

### 🚀 Live Demo
**[https://portfolio-gules-seven-35.vercel.app/](https://portfolio-gules-seven-35.vercel.app/)**

## Architecture
- **Frontend**: React, Vite, Tailwind CSS, Framer Motion, Lucide Icons. Hosted on **Vercel**.
- **Backend**: Node.js, Express, Nodemailer, CORS. Hosted on **Render**.

## Local Development

### 1. Start the Frontend
```bash
cd frontend
npm install
npm run dev
```

### 2. Start the Backend
```bash
cd backend
npm install
npm start
```
*Note: You must configure a `.env` file in the `backend` directory with `EMAIL_USER` and `EMAIL_PASS` (Google App Password) for the contact form to work locally.*
